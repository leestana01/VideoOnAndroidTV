# Contributing

Contributions are welcome through focused pull requests.

1. Open an issue for user-visible behavior changes or architectural work.
2. Keep API 21 compatibility and TV D-pad navigation intact.
3. Add focused tests for parsing, gain, persistence, and regressions.
4. Run `./gradlew lintDebug testDebugUnitTest assembleDebug assembleRelease`.
5. Do not add analytics, undisclosed network traffic, proprietary SDKs, binary signing material, or secrets.
6. Describe device/API/codec test coverage and accessibility impact in the PR.

Commit messages should be concise, imperative, and scoped. By submitting a contribution, you agree that it is licensed under Apache-2.0.
