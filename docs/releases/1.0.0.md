# Vela Player 1.0.0

The first stable release of Vela Player provides a modern, remote-first media experience for Android TV, projectors, and older Android devices down to API 21.

## Included

- Media3 playback with decoder fallback
- Local and removable storage through Android's secure system picker
- D-pad and hardware media-key controls
- Playback resume positions
- 0–400% audio booster
- QR-based phone audio over a trusted local network
- Android share/open intent support for files and network URLs

## Compatibility notes

Codec and resolution support depend on the decoder capabilities of the device. H.264/AAC in MP4 is recommended for the widest compatibility. Direct Bluetooth A2DP Sink mode is unavailable to normal third-party apps on most Android phones; Vela provides phone audio over local Wi-Fi instead.
