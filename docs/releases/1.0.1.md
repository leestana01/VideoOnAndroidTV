# Vela Player 1.0.1

This patch release fixes phone audio synchronization and keeps the playback surface free of persistent menu controls.

## Fixed

- Phone synchronization state is now delivered through a thread-safe cache, avoiding invalid cross-thread Media3 access.
- The phone receiver starts and resynchronizes more reliably, polls twice per second, and reports playback errors clearly.
- Quick actions automatically disappear after five seconds during playback and can be restored with the remote's Menu or Settings key.
- Audio levels above 100% now reacquire the active playback session, apply up to +12 dB gain, and report whether the device accepted the boost effect.
- Release publication now fails if the signing certificate fingerprint cannot be extracted.

## Compatibility

Android 5.0 (API 21) and later remain supported. This release uses the same signing certificate as 1.0.0 and installs as an in-place update.
