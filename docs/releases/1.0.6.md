# Vela Player 1.0.6

This release fixes playback position resets when seeking local videos from SAF, USB, and other `content://` sources.

## Fixed

- Local document playback now uses an original file descriptor with random-access positioning instead of relying on provider stream skipping.
- D-pad Left/Right and hardware rewind/fast-forward retain the requested position after the source is reopened.
- Android 5.0–12 external media reads include the legacy permission required by those platform versions.
- The standard Media3 data source remains available as a compatibility fallback for providers that cannot expose a seekable descriptor.

## Verification

- CI generates and opens a 30-second MP4 through a real `content://` URI on Android 5.0/API 21.
- The device gate plays the video, sends a hardware fast-forward command, and requires the settled playback position to remain beyond eight seconds.
- The verified run moved from 7.603 seconds to 17.603 seconds and remained at the requested position.
- Android Lint, JVM tests, debug assembly, R8 release assembly, installation, launch, and relaunch all pass.

## Compatibility

Android 5.0 (API 21) and later remain supported. This release uses the existing signing certificate and installs as an in-place update.

The release workflow appends the signing certificate SHA-256 fingerprint below. Download both the APK and `.sha256` asset and run `sha256sum -c` before installation.
