# Vela Player 1.0.5

This patch release corrects a zero-duration edge case that could send relative seek operations to the beginning of a video.

## Fixed

- A temporary Media3 duration of `0` is now treated as unknown instead of a real upper bound at 00:00.
- Forward and backward targets use the same overflow-safe boundary calculation.
- D-pad Left/Right and hardware rewind/fast-forward preserve the current playback position while duration metadata is still being resolved.
- Regression tests cover both directions with zero and unknown duration values.

## Compatibility

Android 5.0 (API 21) and later remain supported. This release uses the existing signing certificate and installs as an in-place update.
