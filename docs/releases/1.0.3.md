# Vela Player 1.0.3

This patch release replaces the temporary media list dialog with Vela's own full-screen TV file browser and corrects relative seeking.

## Fixed

- Local folders and removable USB roots now open in a dedicated full-screen Vela browser designed for D-pad navigation.
- Folders and playable media have large focus targets, visible focus states, breadcrumb navigation, and deterministic directory-first sorting.
- Android's system picker is used only for the mandatory initial storage permission grant; browsing and media selection remain inside Vela afterward.
- Left/Right and rewind/fast-forward now calculate an explicit target from the current playback position and clamp it to valid media bounds.
- Unknown or non-seekable streams no longer jump to 00:00; Vela reports that seeking is unavailable instead.

## Compatibility

Android 5.0 (API 21) and later remain supported. This release uses the existing signing certificate and installs as an in-place update.
