# Vela Player 1.0.2

This patch release separates home and playback states, adds a remote-first storage browser, and restores dependable transport controls.

## Fixed

- The player surface is hidden and detached on the home screen; Back returns cleanly from playback to home.
- Granted local folders and removable USB drives can be traversed through Vela's D-pad-friendly hierarchical browser.
- Common media extensions are recognized when a storage provider reports a generic MIME type.
- Media with a saved position prompts to resume or start from the beginning.
- D-pad Left/Right and hardware rewind/fast-forward seek by 10 seconds and display immediate feedback.
- Quick actions appear on pause and remain visible until playback resumes; D-pad Up, Menu, and Settings also restore them.

## Compatibility

Android 5.0 (API 21) and later remain supported. This release uses the same signing certificate as 1.0.0 and installs as an in-place update.

## Verification

The release workflow appends the signing certificate SHA-256 fingerprint below. Download both the APK and `.sha256` asset and run `sha256sum -c` before installation.
