# Vela Player 1.0.4

This patch release makes Vela's own browser the only media-selection entry point, restores seeking for local providers with incomplete timeline flags, and hardens phone-audio delivery.

## Fixed

- The home screen now opens Vela's full-screen media browser directly instead of Android's single-file picker.
- First-time USB or folder access is requested from inside Vela; Android's system UI is used only for the mandatory storage permission grant.
- Local media with a known duration can seek even when its document provider omits Media3's seekability flag.
- Invalid positions, unprepared items, and genuinely non-seekable streams remain protected from accidental 00:00 resets.
- Phone audio now resolves file size through the underlying descriptor when USB providers omit metadata.
- The relay serves explicit HEAD and byte-range responses and derives browser-compatible MIME types from filenames when providers report generic data.
- The phone page preloads metadata, uses a video-capable media element, synchronizes from a prefetched TV snapshot, and reports actionable browser error names.

## Compatibility

Android 5.0 (API 21) and later remain supported. This release uses the existing signing certificate and installs as an in-place update.
